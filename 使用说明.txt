InternToolkit 使用说明
======================

【快速开始】

  1. 将 InternToolkit-v1.0.zip 解压到任意文件夹
  2. 双击「启动.bat」（只需成功运行一次）
  3. 以后可双击桌面快捷方式「InternToolkit」，或依赖开机自启


【开机自启】

  首次运行「启动.bat」后，会自动注册 Windows 计划任务。
  此后每次登录 Windows，约 30 秒后会自动打开优先级工具。
  无需重复安装。

  若移动或删除了文件夹，开机自启会失效。
  解决：双击当前目录下的「启动.bat」一次，会自动修正计划任务路径。


【离线使用 · 不需要联网】

  本工具可在完全断网环境下正常使用。

  · 所有页面文件保存在本机解压目录内
  · 本地服务仅监听 127.0.0.1（本机），不对外网开放端口
  · 不连接任何远程服务器，不上传、不同步任何数据
  · 不收集账号、设备信息或使用行为
  · 无注册、无登录、无云备份

  断网时功能完整可用：添加任务、拖拽排序、完成勾选、
  数据留存、快照、导出 JSON/CSV 均可正常操作。


【隐私与数据 · 不共享信息】

  你的任务与操作记录默认存在两处（均在本机）：
  · 浏览器 localStorage（按访问地址区分）
  · data/storage.json（通过「启动.bat」打开时自动同步）

  若曾用不同方式打开（例如双击 html、换文件夹、换 zip 解压路径），
  浏览器会当成「新网站」，页面会像没数据一样——并不是一定被删了。

  找回步骤：
  1. 双击「恢复旧数据.bat」，看旧页面是否还有任务
  2. 若有：底部「导出 JSON」→ 再用「启动.bat」打开 →「导入备份」
  3. 若无：说明未导出且旧地址数据已清除，无法恢复

  今后请始终用「启动.bat」打开，数据会写入 data/storage.json，不易再丢。

  本工具不含广告、不含统计埋点、不含外部 API 调用。


【本地服务说明】

  「启动.bat」会在本机启动一个轻量静态文件服务（端口 17890），
  仅用于让浏览器以固定地址访问页面，便于数据持久保存。
  该服务只在本机运行，局域网及互联网均无法访问。


【文件说明】

  启动.bat       唯一入口，首次运行 = 安装 + 打开
  priority.html  优先级排序（艾森豪威尔四象限）
  index.html     实习生能力指南
  config.ini     可选配置（一般无需修改）
  scripts/       内部脚本，无需手动打开
  使用说明.txt   本文件


【数据备份建议】

  · 建议每周在 priority 页面底部导出一次「分析包」
  · 换电脑：旧电脑导出 → 新电脑解压安装 → 导入 JSON
  · 重装系统前务必先导出备份


【系统要求】

  Windows 10 / 11
  任意现代浏览器（Edge、Chrome 等）
  无需安装 Node、Python 或其他软件


【常见问题】

  Q：必须联网吗？
  A：不需要。完全离线可用。

  Q：历史记录突然全空了？
  A：多半是换了打开方式（未用启动.bat）或浏览器清过数据。先运行「恢复旧数据.bat」尝试找回。

  Q：数据会上传到网上吗？
  A：不会。所有数据仅在本机浏览器本地存储。

  Q：别人能通过网络看到我的任务吗？
  A：不能。服务仅绑定本机 127.0.0.1。

  Q：压缩包给别人，对方怎么用？
  A：解压 → 双击「启动.bat」一次 → 完成，今后对方电脑也会开机自启。

  Q：如何取消开机自启？
  A：Windows「任务计划程序」中删除「InternToolkit-DailyBrowser」，
     或联系提供方获取取消脚本。
